# 几何路线走完:能从"框与构件的关系"榨出的信息已用尽  (2026-08-16 晚)

## 四个问题,一个有效

| 问题 | 做法 | 结果 |
|---|---|---|
| 框在构件**外**吗? | 正向门控 | **有效,已采纳**(误报 1.86 -> 1.41 箱-张) |
| 框在**其他构件**内吗? | 负门控(路由器其余四类) | 物理上不成立(`18_negative_gate_fails.md`) |
| 框在构件内的**位置**? | 构件相对坐标 | **无分离**(本文档) |
| 框相对构件的**尺寸**? | 构件相对宽高 | 与 B 级混淆,不可用(本文档) |

## 构件内位置:比全图坐标更强的否定

`09_what_the_errors_are.md` 曾在**全图坐标**下比较误报与真阳性的位置,发现几乎相同
(纵向中位都是 0.64),据此关闭了"第二道几何门控"。但全图坐标混淆了两件事:
**构件在画面何处**、**损伤在构件何处**。俯拍与平拍会把同一物理位置放在不同画面高度。

门控现在提供了构件框,故第二个量首次可测。

| | 真阳性(48 框) | 误报(37 框) |
|---|---|---|
| 纵向 cy 中位 | 0.65 | 0.64 |
| 横向 cx 中位 | 0.50 | 0.56 |
| 上/中/下三分之一 | 15% / 42% / 44% | 8% / 54% / 38% |
| 相对宽 x 高 中位 | 0.22 x 0.23 | 0.19 x 0.15 |

**纵向中位差 0.01。** 除掉"构件在画面何处"这一项之后,损伤在构件上的位置**仍无分离**。
这比全图坐标下的结论更强 —— 那个结论本可能是被取景差异掩盖的。

## 唯一露头的差异不可用

误报**更扁**:相对高度中位 0.15,真阳性 0.23。但分布重叠严重
(真阳性 p25 已很低,误报 p75 与真阳性中位相当),以此过滤会连带删除大量真损伤 ——
与负门控的失败同型(`ov=0.9` 那样宽松都打破了 recall)。

更要紧的是它**在物理上说得通但方向不利**:B 级损伤占误报的 83%
(`09_what_the_errors_are.md`),而 B 级本身就细微、形状扁。
**"扁"不是误报的特征,是 B 级的特征。**

## 这从第三个角度指向同一个待决问题

    误报构成      78% 是"无中生有",83% 是 B 级
    误报分数      中位 0.207,真阳性 0.439 —— 刚过线的低分检测
    误报几何      与真阳性无分离;唯一差异与 B 级混淆

三条独立测量都把剩余的误报问题指回 **B 级本身**,而 B 正是标注矛盾最集中的等级
(baseline 配置记载 11 处等级矛盾中 6 处是柱脚 B-vs-C)。

**几何解决不了剩下的部分。** 剩余两个杠杆都不在开发侧:

1. `14_the_one_decision_for_the_client.md` 的取舍 —— B 级 recall 能否低于 0.70
