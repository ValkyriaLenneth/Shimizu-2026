## 必须与结果一并说明的三条

1. **"四项 >=0.70" 是这 45 张图的性质,不是模型的性质。** 即使采纳翻转,
   四项达标也只在 46.4% 的自助重采样中成立。D 级仅 10 框,recall 0.700 的
   Wilson 95% 区间是 [0.40, 0.89]。
2. **数字是上界。** 阈值在该测试集上调,epoch 亦按该测试集选(数据集名即
   `test_as_valid`)。缓解见 `04_data_integrity.md` §3。
3. **误报仍高。** 72% 的健全柱脚会至少发一个框。检查员 92% 的过目负担来自
   健全照片,而非受损照片的 precision —— 见 `06_negatives_verdict.md` 末节。

## 对客户的请求(优先级高于任何模型改进)

1. **扩充 C / D 级测试样本。** 现 C 15 框 / D 10 框。当前样本量下,
   真实提升无法在交付协议上被可靠测出。
2. **补充健全柱脚照片,但仅用于评测。** 现 29 张(去重后),
   86% 的 Wilson 区间 [0.69, 0.94]。**在数量足以改变训练分布之前不应进训练集** ——
   两条入训路径均已实测有害,见 06 / 07。

## 当日方法学纪律(适用于后续全部实验)

- 训练类结论须经 **>=3 种子** 或 **同种子配对 + 事先门槛**;单跑复现性仅 0.06-0.10。
- 推理类结论须经 **留出验证**;仅有自助区间不足以排除挑选偏差。
- **固定 epoch 比较**,不取各自最佳 —— 最大值的上尾不随汇总收敛。
- 当日据此撤回**八项**声称的提升。其中两项在进入文档前被拦下;
  一项(主干冻结 +0.188)已写入文档后被交付协议推翻,更正见 12 / 13。
- **CV 的配对比较仅在被比较的配置对训练起点的偏离速度相当时有效**
  (见 12)。改变学习率、冻结、训练量的干预不满足该前提。
