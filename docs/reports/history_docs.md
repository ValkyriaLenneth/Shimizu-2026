8. 改善方針

今回の評価では、主な誤分類は RC壁 と 内壁 の間に集中していた。ただし、該当画像を確認すると、画像上の見た目だけでは人間でも判断が難しい例が含まれている。したがって、この課題はモデル構造だけで解決するというより、データ側で両クラスの違いがより明確に表れるようにすることが重要である。

特に、RC壁 と 内壁 の判定基準が画像上の局所的な質感だけでは表れにくい場合、顧客側で以下のような情報整理・データ追加を検討いただく必要がある。

改善方向
内容
判定基準の明確化
RC壁 と 内壁 をどの視覚的・構造的根拠で区別するかを整理する。
区別しやすい画像の追加
壁の全体位置、周辺構造、柱・梁・開口部との関係が分かる画像を追加する。
曖昧画像の扱いの整理
人間でも判断が難しい画像を、学習対象に含めるか、別カテゴリ・確認対象にするかを決める。
低信頼度結果の確認運用
RC壁 / 内壁 の確率が近い画像は自動確定せず、専門者確認に回す。

モデル面では、追加データと判定基準が整理された後に、アンサンブル重みの調整、より強い backbone の検証、または RC壁 / 内壁 専用の補助分類器を検討する。まずはモデル変更よりも、クラス間のデータ区別度を高めることが優先である。

9. まとめ

本評価では、EfficientNet-B0、ResNet34、アンサンブルモデルの 3 種類を比較した。その結果、アンサンブルモデルが最も高い性能を示し、テストデータ 450 枚に対して Accuracy 0.8111、Macro F1 0.8192 を達成した。

一方で、RC壁 と 内壁 の相互混同が主要な課題として残っている。この課題は、単純なモデル性能不足だけでなく、画像上の視覚特徴が近いこと、局所画像では構造情報が不足しやすいことに起因している。

今後は、RC壁 / 内壁 の境界サンプル追加、二段階分類、アンサンブル重みの最適化、低信頼度画像の人手レビュー運用を組み合わせることで、実運用上の精度と安定性をさらに向上できると考えられる。

2. アプローチ：「先に領域を切り出す」設計へ
2.1 考え方の転換
この問題を解決するために、推論の最初のステップとして「画像の中のどこに何の部位があるか」を検出し、部位ごとに領域を切り出した上で、対応する専用モデルへ転送する方式を採用しました。
つまり、YOLOは損傷の判定には一切関与せず、「適切な専用モデルに正しく割り振ること」だけを担当します。 これにより、既存の専用モデル資産をそのまま再利用しながら、複数部位が混在する画像にも対応できます。

3. 課題：既存のアノテーションデータは使えない
3.1 既存データの構造
部位識別モデルを学習するには、「この画像のこの領域が天井（または内壁・RC壁・RC柱）である」というラベルが必要です。
しかし既存のアノテーションデータは損傷箇所と損傷等級の記録を目的として作成されており、構造が根本的に異なります。

3.2 既存データが使えない理由のまとめ
- データが部位ごとに独立したデータセットとして分割されており、複数部位を同一画像で扱う構造になっていない
- ラベルが表しているのは「損傷の位置と程度」であり、「建物部位の領域」ではない
- 部位識別に必要な「部位全体を囲む大まかな領域」のアノテーションが存在しない

4. 解決策：Gemini  による自動アノテーション
4.1 採用の背景
新規ラベリングには通常、多大な人的コストが伴います。 しかし今回のフェーズで確認したいのは「この設計が原理的に機能するかどうか」であり、最終的な高精度ラベルセットの整備ではありません。
そのため、Gemini 3.1 Pro（Vision）を活用した自動ラベリングを採用しました。
採用理由：
- 部位識別モデルに必要な精度は「正しい専用モデルに渡せること」であり、ピクセル単位の精密な境界は不要
- 主要部位の領域とその文脈が含まれていれば、バウンディングボックスは多少大まかでも機能する
- VLMにより、4クラスをまたいだ初期ラベルを短期間・低コストで生成可能
- 後工程での人手QA・反復改善により品質を段階的に向上できる設計

Part 4　残課題に対する改善の方向性
4.1　モデル面での改善
今後のモデル改善は以下の 2 軸で推進することを提案します。
1. AI 合成データの補充： RC柱と壁類が混同されやすいシーンを重点的にカバーします。具体的には、壁柱境界・窓際・廊下端部・柱体が不明瞭なケース・柱体が画面の一部のみに映るケースなどを想定しています。
2. 出力ルールの最適化： 単純に検出結果を増やすのではなく、ルールベースで最終出力を洗練させます。例えば、自動識別の信頼度が中程度でRC柱 / 壁類の混同リスクが高い場合には、候補結果を補助情報として保持しつつ、全結果をそのまま最終出力に混在させることは避ける設計を検討します。
なお、少数の FN を回復しようとして FP を大量に再導入し、ユーザーが確認する結果が再び煩雑になることは、避けるべき点として留意が必要です。引き続き慎重に検証を進めます。
4.2　UI / プロダクト戦略の提案
UI において「自動識別領域の確認」ステップの追加を提案します。ユーザーが写真をアップロードした後、システムがまず自動識別した建築領域と種類を表示し、ユーザーが確認または手動修正を行ってから損傷レベルの最終結果を出力する流れです。
ユーザーが写真をアップロード
  → システムが建築領域を自動で枠出し
  → 種類を表示：天井 ／ 壁類 ／ RC柱
  → ユーザーが確認または手動修正
  → 損傷レベルの最終結果を出力

3. RF-DETRを選定した理由
RF-DETRは比較的新しい物体検出モデルです(2025年論文発表)。YOLO系モデルと同様に、クラス分類とバウンディングボックスの形式で出力を行います。
その先進性はTransformerアーキテクチャに基づいています。TransformerはLLM（大規模言語モデル）の基盤構造であり、視覚領域においてもViT（Vision Transformer）が重要なバックボーンとして確立されています。RF-DETRはこの視覚Transformer技術を物体検出に応用しており、複雑な画像理解において優れた基盤を持ちます。
また、事前学習済みモデル（Pre-trained Model） の活用も重要な選定理由です。RF-DETRは建築検査画像をゼロから学習するのではなく、大規模な汎用視覚データで基本的な視覚特徴を事前に学習した上で、本プロジェクトのデータでファインチューニングを行います。データ量が限られるプロジェクトにおいて、この転移学習のアプローチは特に有効です。
本検証では RFDETRMedium を採用しました。このサイズは表現能力とコストのバランスを考慮した選択であり、小型モデルより高い表現力を持ちながら、トレーニング・推論コストは許容範囲内に収まります。
エグ面では、RF-DETRは既存のデータ構成とトレーニングコードに対応可能です。推論環境（NVIDIA T4 GPU）もRF-DETR Mediumの推論要件を満たしており、移行コストはトレーニングと評価の工数が中心となります。

天井の主な難点はBクラスにある。Bクラスの損傷は細長いひび割れ・小面積の剥離・局所的な線状変化として現れることが多く、対象枠が小さく形状が細い上に、配管・照明器具・目地・背景テクスチャによるノイズの影響を受けやすい。そのため、天井モデルは内壁のようにPrecisionとRecallを同時に高めることが難しく、現在の結果は実用上の妥協点に相当する。Recallは YOLO9の低水準から引き上げつつ、Precisionも実用範囲内に収まっている。

3. RC壁モデル
RC壁のRF-DETR最終結果はPrecision 0.632、Recall 0.750である。元のYOLO9 raw（Precision 0.585）比でPrecisionが向上しており、前回報告のRecall 0.720に対してもRecallが小幅改善している。
RC壁の結果が内壁やRC柱ほど高くない主な要因は、Cクラスが依然としてボトルネックとなっていることである。BクラスとDクラスのRecallはそれぞれ0.857・0.875に達しているが、CクラスのRecallは0.500にとどまっている。RC壁のCクラスは大面積の剥落・ひび割れ・局所的な汚染・補修跡として画像上に現れることが多く、B/Dとの境界が内壁サンプルほど明確でない。また、RC壁と内壁は外観上の類似性が高いため、局所的な視覚特徴のみで判定する場合、モデルはCクラスの判定を保守的に寄せる傾向がある。

5. 天井・RC壁の結果が他の類別より低い理由
現時点の4つの下流モデルを俯瞰すると、RC柱と内壁への移行効果が最も顕著であり、天井とRC壁もYOLO9からの改善は確認されるものの、絶対指標ではそれほど高くない。主な要因は以下である。
第一に、対象形態の違い。 天井Bクラスは細いひび割れや小さな枠として現れることが多く、実際の対象面積が小さいため、わずかなずれがマッチング結果に影響する。一方、内壁やRC柱の損傷は安定した局所視覚パターンを形成しやすい。
第二に、クラス境界の違い。 RC壁のCクラスはB/Dおよび一部の内壁損傷と視覚的に重複している。モデルは損傷を全く検知できないわけではなく、Cクラスの判定において保守的な方向にバイアスがかかっているため、overall recallがCクラスによって引き下げられている。
以上より、今回の結果は次のように解釈するのが妥当である。RF-DETRは4類別すべてにおいてYOLO9の代替としての実現可能性を実証した。RC柱と内壁はすでに十分に成熟しており、RC壁は前回報告をわずかに超過した。天井は前回報告のRecallを依然下回っており、継続的な最適化が必要である。

8. 現時点の結論
今回の展開により、RF-DETRは自動認識モデルおよび4つの下流損傷等級モデルのすべての主要類別をカバーするに至った。
- 内壁およびRC柱の結果が最も成熟しており、YOLO9を明確に上回っている。
- 天井とRC壁は内壁・RC柱ほど高い指標ではないものの、可視化事例から実際の補完的検出効果が確認できる。RC壁は前回報告のRecallを小幅に超過した。天井は前回報告のRecallを未だ下回っているが、これはRF-DETRが完全に適合しないということではなく、小目標・クラス境界・hard negativeに対する継続的な最適化が必要であることを示している。
